# Jejaku - Precise AR Photo Anchoring Implementation

## Focus: Exact Coordinate Placement with Altitude & Camera Orientation

This guide focuses on **precise AR anchor placement** ensuring photos appear **exactly** where they were captured, including:

- ✅ Altitude (meters above sea level)
- ✅ Camera orientation (heading/yaw, pitch, roll)
- ✅ Cross-platform compatibility (Android ARCore + iOS ARKit)
